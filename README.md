# 项目

记录学习与竞赛相关实践工程，包含控制程序、视觉识别代码及实物演示。

## 目录

### 1. 循迹小车（来源于2026年H题：车载平衡滚球运动控制系统）
- 硬件平台：TI MSPM0G3507。
- 内容：八路循迹小车工程，包含小车控制相关 C 代码与实物运行视频。

### 2. 色块追踪
- 硬件平台：STM32F103C8T6 与 OpenMV H7 Plus。
- 内容：包含 OpenMV 色块阈值识别判断、Keil工程和实物演示视频。

### 3. 2023年E题：运动目标控制与自动追踪系统
- 硬件平台：STM32F103C8T6 与 OpenMV H7 Plus。
- 内容：包含基础题和发挥题的Keil工程和 OpenMV 代码。

### 4. 2025年E题：简易自行瞄准装置
- 硬件平台：STM32F103C8T6 (舵机控制) 与 OpenMV H7 Plus。
- 内容：包含基础题2、3问Keil工程和 OpenMV 代码。发挥部分的视觉识别与舵机控制尚未完整实现，可基于现有代码进一步开发。
